how to deploy large models locally and use the VS Code plugin Continue for code editing, enabling efficient coding without an internet connection.
November 23, 2026 · 2 min · Local AI Lab | Translations:
  • Zh-Cn

Deploying large models locally and using the VS Code plugin Continue for code editing allows you to write code efficiently even without an internet connection. This article will provide a detailed guide on how to deploy a local large model on a Windows 11 system using Ollama and use the VS Code plugin Continue for real-time code suggestions. My machine configuration includes an NVIDIA RTX 4070 SUPER with 12GB VRAM, an AMD CPU, and 32GB RAM. Installed models include qwen2.5:14b, gemma4:12b, and hermes-agent.

Deploying Ollama#

First, ensure you have installed Ollama, version 0.34.2. Next, you need to download and configure the model. Below is an example of a Modelfile configuration for qwen2.5:14b:

FROM ollama/qwen2.5:14b
SYSTEM Windows 11
PARAMETER temperature 0.7
PARAMETER num_ctx 8192
PARAMETER stop "EOF"

Deploy the model using the following Ollama command:

ollama run qwen2.5:14b

Configuring the VS Code Plugin Continue#

To use the VS Code plugin Continue, you first need to install the plugin. After installation, you need to configure the plugin to connect to your locally deployed model. In VS Code, open the command palette (Ctrl+Shift+P), then enter “Continue: Connect” and select your local Ollama instance.

Next, you need to set up the VS Code launch configuration so that it automatically connects to the local model every time you open VS Code. In VS Code settings, add the following configuration:

{
    "continue.server": "http://127.0.0.1:8000",
    "continue.model": "qwen2.5:14b",
    "continue.context": 4096
}

With this configuration, you can use VS Code for code editing and code suggestions without an internet connection.

Performance Optimization#

To better utilize the local model, pay attention to its performance. On my machine, using qwen2.5:14b, the throughput is approximately 49 tok/s with 4096 context, 100% GPU usage, and 9.5GB VRAM occupied. With 32768 context, the throughput is around 15-20 tok/s, with 34% CPU + 66% GPU usage, and approximately 15GB memory used in total.

You can optimize performance by adjusting the num_ctx parameter, such as setting num_ctx to 4096 to achieve better performance with lower memory usage.

Conclusion#

With the guidance provided in this article, you should be able to deploy large models in a local environment and use the VS Code plugin Continue for real-time code editing. This technology enables efficient coding and development even without an internet connection, significantly enhancing the flexibility and practicality of local development environments.
