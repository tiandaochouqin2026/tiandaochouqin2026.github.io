Running 14B Model with 12GB VRAM: Practical Measurements on Q4 Quantization, Context Window, and CPU/GPU Hybrid

Real-world VRAM allocation measurements for Qwen2.5-14B on RTX 4070 SUPER 12G: GPU/CPU ratio and inference speed under different context lengths.
September 21, 2026 · 2 min · Local AI Lab | Translations:
  • Zh-Cn

Problem#

How much context can a 12GB VRAM handle when running a 14B model? This is one of the most critical questions when deploying large models locally. This article answers it with real data.

Test Environment#

  • GPU: RTX 4070 SUPER (12GB)
  • Model: Qwen2.5-14B-Instruct, Q4_K_M quantization, weights around 9GB
  • Inference Engine: Ollama 0.34
  • Monitoring Command: ollama ps

Practical Measurements#

Context Length (num_ctx) Model Usage GPU/CPU Ratio Inference Speed
4096 9.5 GB 100% GPU ~49 tok/s
16384 ~11 GB 100% GPU (critical) ~40 tok/s
32768 ~15 GB 34% CPU + 66% GPU ~15-20 tok/s
65536 VRAM overflow Mostly CPU Unavailable

Principles#

The weights of a 14B Q4 model are around 9GB. The remaining 3GB VRAM must accommodate:

  • KV cache: Approximately hundreds of MB per 1K token context (depends on model layers and hidden dimensions)
  • Activation values and temporary buffers

The longer the context, the larger the KV cache. Once VRAM capacity is exceeded, Ollama automatically moves some layers to system memory, exchanging data via PCIe, which is why the speed drops significantly.

Practical Recommendations#

  1. Use 4096-8192 context for daily conversations: Sufficient for most chat scenarios, and the fastest.
  2. Use 16384 for long document analysis: Critical value for 12GB VRAM, still runs full GPU.
  3. Use 32768 for code/Agent: Accept the speed penalty of CPU hybrid if necessary.
  4. Avoid blindly setting 128K: Qwen2.5 natively supports 128K context, but that requires tens of GB VRAM.

How to Adjust Context Length#

Controlled via the num_ctx parameter in Ollama. Configure in OpenClaw:

{
  "params": { "num_ctx": 16384, "keep_alive": "15m" }
}

Or set directly in Ollama’s Modelfile.

Conclusion#

The sweet spot for running a 14B model with 12GB VRAM is 8K-16K context. For longer contexts, either upgrade to larger VRAM (24GB+), or accept the speed trade-off of CPU hybrid. Larger models aren’t always better; the right size is key.
