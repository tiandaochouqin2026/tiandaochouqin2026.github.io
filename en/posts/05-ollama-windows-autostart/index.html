correct-way-to-auto-start-ollama-on-windows-without-black-window

September 21, 2026 · 2 min · Local AI Lab

Deploying Ollama and setting it up to auto-start on Windows can greatly enhance daily use. However, using the default command-line method may result in a black window popping up at each boot, affecting aesthetics and user experience. This article will provide a detailed guide on how to set up Ollama to auto-start on Windows without displaying a black window, ideal for users needing Ollama to run continuously.

Installing Ollama#

First, you need to install Ollama on your Windows system. Visit the Ollama official website or related resource pages to download the appropriate installation package for Windows. Follow the official documentation to complete the installation steps, ensuring that Ollama is correctly installed.

Preparing the Run Script#

To avoid the black window, we need to prepare a run script. Create a new text file named run_ollama.bat, and add the following content:

@echo off
start /b "" "C:\Path\To\Ollama.exe"

Make sure to replace C:\Path\To\Ollama.exe with the actual path to the Ollama executable file. The start /b parameter is used to start the program in the background without displaying the command prompt window.

Creating a Windows Service#

Next, we need to use the sc command to create a Windows service to manage Ollama’s startup. Open the command prompt and enter the following command:

sc create OllamaService binPath= "C:\Path\To\run_ollama.bat"

Ensure that C:\Path\To\run_ollama.bat is replaced with the actual path to the run script. After creating the service, you can use the following command to set it to auto-start:

sc config OllamaService start= auto

Verification and Testing#

After completing the above steps, restart your computer and check if Ollama auto-starts without displaying a black window. If everything is set up correctly, you should see Ollama running in the background.

Configuration Optimization#

For further optimization, consider using Task Scheduler to periodically check if Ollama is running normally and automatically restart it if the process does not exist. Create a new task with the trigger set to “At startup” and the action set to start the Ollama run script.

<Triggers>
    <BootTrigger />
</Triggers>
<Actions>
    <Exec>
        <Command>C:\Path\To\run_ollama.bat</Command>
    </Exec>
</Actions>

Conclusion#

By following the above steps, you can set up Ollama to auto-start on Windows without displaying a black window, ensuring continuous and stable operation while enhancing the system’s aesthetics and user experience. I hope this article is helpful to you.
