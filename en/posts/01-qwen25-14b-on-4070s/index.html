Full Guide to Running Qwen2.5-14B on RTX 4070 SUPER 12G (Windows + Ollama)

A comprehensive guide to deploying Qwen2.5-14B on Windows with a 4070 SUPER 12G: download, model pull, local network access, and performance testing.
September 21, 2026 · 2 min · Local AI Lab

Hardware and Conclusion#

Item Configuration
GPU RTX 4070 SUPER (12GB VRAM)
Model Qwen2.5-14B-Instruct (Q4_K_M quantization, approximately 9GB)
Software Ollama for Windows 0.34
Performance Approximately 49 tokens/s after warm-up (100% GPU)

Conclusion: 12GB VRAM is sufficient for running 14B Q4 models. The model itself is about 9GB, and with the context KV cache, it does not exceed VRAM capacity.

Step 1: Install Ollama#

Download the Windows installer from ollama.com/download and run it silently by double-clicking.

Troubleshooting Tip: The official website hosts the installer on GitHub Releases. If you are in China and direct access fails with “Could not resolve host: github.com”, use a GitHub mirror (such as ghproxy) to retry.

After installation, open cmd to verify:

ollama --version

Step 2: Pull the Model#

ollama pull qwen2.5:14b

The model is approximately 9GB, and the download speed depends on your network. Confirm the download with ollama list.

Step 3: Validate Inference#

ollama run qwen2.5:14b

Enter a sentence directly to test. The first inference will load the model into VRAM, taking about 10-20 seconds.

Step 4: Open Local Network Access (Optional)#

By default, Ollama only listens on 127.0.0.1:11434, which is not accessible from other devices. Set the environment variable and restart:

[Environment]::SetEnvironmentVariable('OLLAMA_HOST','0.0.0.0','User','User')

After restarting the Ollama service, local network devices can access the API via http://<your LAN IP>:11434.

VRAM Usage Testing#

Context Length GPU Usage Speed
4096 100% GPU ~49 tok/s
32768 34% CPU + 66% GPU Significantly slower

With 12GB VRAM, the KV cache space is limited after loading 14B Q4. Longer contexts will overflow to memory, reducing speed. 4K context is sufficient for daily conversations.

Final Thoughts#

Running a 14B model locally is not about being “better than GPT-4”, but about: no data leaving the machine, no API fees, offline use, and customizable settings. If you have a card with more than 12GB VRAM, this step is worth taking.
