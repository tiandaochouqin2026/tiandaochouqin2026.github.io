Integrate Ollama language model deployed locally with Telegram via OpenClaw.
September 24, 2026 · 2 min · Local AI Lab | Translations:
  • Zh-Cn

Deploying a local language model and making it accessible on mobile devices can significantly reduce data transfer costs and improve response times. This tutorial explains how to integrate a locally deployed Ollama model with Telegram using OpenClaw, enabling direct conversations with the local model on your phone.

Environment Setup#

  • Hardware: Minimum requirement is 4GB RAM, recommended 8GB RAM or higher.
  • Software: Windows 10 or higher, Python 3.8 or above.
  • Model: Download and install Ollama, it is recommended to use a smaller model like llama-7b to reduce resource consumption.

Install OpenClaw#

  1. Clone the OpenClaw repository:

    git clone https://github.com/OpenClaw/OpenClaw.git
cd OpenClaw

  2. Install dependencies:

    pip install -r requirements.txt

Configure Ollama#

  1. Install the Ollama model:

    ollama install llama-7b

  2. Start the Ollama service:

    ollama run llama-7b

  3. Set the Ollama API address:

    {
    "api": "http://localhost:5000"
}

Configure OpenClaw#

  1. Edit the OpenClaw configuration file config.yaml and add the Ollama API address:

    ollama_api:
    host: "localhost"
    port: 5000

  2. Install the Telegram Bot API:

    pip install python-telegram-bot

  3. Create a Telegram Bot:

    • Visit https://t.me/BotFather.
    • Generate a new Telegram Bot and obtain the API Token.

  4. Edit the OpenClaw configuration file and add the Telegram Bot Token:

    telegram:
    token: "YOUR_TELEGRAM_BOT_TOKEN"

Integrate Telegram and Ollama#

  1. Write the message handling logic for the Telegram Bot to interact with Ollama. For example, when receiving a user message, call the Ollama API to process it: 
    from telegram import Update
from telegram.ext import Updater, CommandHandler, MessageHandler, Filters, CallbackContext
import requests

def start(update: Update, context: CallbackContext) -> None:
    update.message.reply_text('Hello! Send me a message and I will reply with the OpenClaw response.')

def echo(update: Update, context: CallbackContext) -> None:
    response = requests.get(f"http://localhost:5000/generate", json={"prompt": update.message.text})
    update.message.reply_text(response.json()['response'])

def main() -> None:
    updater = Updater("YOUR_TELEGRAM_BOT_TOKEN")
    dispatcher = updater.dispatcher

    dispatcher.add_handler(CommandHandler("start", start))
    dispatcher.add_handler(MessageHandler(Filters.text & ~Filters.command, echo))

    updater.start_polling()
    updater.idle()

if __name__ == '__main__':
    main()

Run OpenClaw#

  1. Start the OpenClaw service:

    python start.py

  2. Interact with your Bot on Telegram to verify that messages are correctly passed to Ollama and receive responses.

Conclusion#

By following the above steps, you have successfully integrated a locally deployed Ollama model with Telegram, allowing you to directly converse with the model on your phone. This not only provides convenience but also enhances data security and privacy. I hope this tutorial helps you quickly achieve this functionality and inspires your development projects.
