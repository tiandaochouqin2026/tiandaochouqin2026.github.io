在本地搭一个 RAG 知识库：把 PDF 和笔记交给 qwen2.5

在本地搭建一个 RAG (Retrieval-Augmented Generation) 知识库，能够让 qwen2.5 更好地处理和回答与本地文档相关的问题。这篇文章将介绍如何利用 Ollama 服务将 PDF 和笔记集成到本地知识库中。 准备工作 确保已经安装了 ollama，并可以正常使用。 准备好需要导入的 PDF 和笔记文件，放在一个易于访问的目录下。 安装依赖 pip install ollama 上传 PDF 文件 首先将 PDF 文件上传到本地服务器的指定目录。 cd /path/to/your/files 使用 ollama ingest 命令将 PDF 转换并上传到知识库。 ollama ingest -t pdf -i /path/to/your/files/*.pdf -o /path/to/your/output -t 参数指定了文件类型，这里是 pdf。 -i 参数指定了输入文件路径。 -o 参数指定了输出目录，用于存放生成的向量文件。 整合笔记文件 将笔记文件（例如 Markdown 文件）上传到服务器。 使用 ollama ingest 命令将笔记文件转换并上传。 ollama ingest -t markdown -i /path/to/your/note/*.md -o /path/to/your/output -t 参数改为 markdown。 -i 参数指定笔记文件的路径。 配置知识库 创建或修改 ollama.yaml 文件，配置知识库。 sources: - name: local-kb type: local path: /path/to/your/output 使用 ollama create 命令创建知识库。 ollama create local-kb -f ollama.yaml 启动服务 ollama run local-kb 现在，你就可以通过 Ollama 提供的 API 与本地知识库进行交互了。 ...
