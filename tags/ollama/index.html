Setting up a RAG (Retrieval-Augmented Generation) knowledge base locally allows qwen2.5 to better handle and answer questions related to local documents. This article will introduce how to use the Ollama service to integrate PDFs and notes into a local knowledge base. Preparation Ensure that ollama is installed and can be used normally. Prepare the PDF and note files to be imported and place them in an easily accessible directory. Install Dependencies pip install ollama Upload PDF Files First, upload the PDF files to the designated directory on the local server. cd /path/to/your/files Use the ollama ingest command to convert and upload the PDF files to the knowledge base. ollama ingest -t pdf -i /path/to/your/files/*.pdf -o /path/to/your/output The -t parameter specifies the file type, which is pdf in this case. The -i parameter specifies the input file path. The -o parameter specifies the output directory, where the generated vector files will be stored. Integrate Note Files Upload the note files (e.g., Markdown files) to the server. Use the ollama ingest command to convert and upload the note files. ollama ingest -t markdown -i /path/to/your/note/*.md -o /path/to/your/output Change the -t parameter to markdown. The -i parameter specifies the path to the note files.
