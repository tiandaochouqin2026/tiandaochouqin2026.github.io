Windows 开机自启 Ollama 的正确姿势（不弹黑窗口）

本文将详细介绍如何在 Windows 系统下实现 Ollama 的开机自启动，并且不弹出黑窗口，适合需要长时间运行 Ollama 服务的用户。
September 21, 2026 · 2 min · Local AI Lab

在 Windows 系统中部署 Ollama 并实现开机自启动可以极大地方便日常使用。然而，直接使用默认的命令行方式可能会导致每次开机时弹出黑窗口，影响美观和用户体验。本文将详细介绍如何在 Windows 系统下实现 Ollama 的开机自启动，并且不弹出黑窗口，适合需要长时间运行 Ollama 服务的用户。

安装 Ollama#

首先，你需要在 Windows 系统中安装 Ollama。访问 Ollama 官方网站或相关资源页面，下载适合 Windows 系统的安装包。按照官方提供的文档完成安装步骤，确保 Ollama 软件已经正确安装。

准备运行脚本#

为了不弹出黑窗口，我们需要准备一个运行脚本。创建一个新文本文件，命名为 run_ollama.bat，并在其中添加以下内容：

@echo off
start /b "" "C:\Path\To\Ollama.exe"

确保将 C:\Path\To\Ollama.exe 替换为实际的 Ollama 可执行文件路径。start /b 参数用于在后台启动程序而不显示命令提示符窗口。

创建 Windows 服务#

接下来，我们需要使用 sc 命令创建一个 Windows 服务来管理 Ollama 的启动。打开命令提示符，输入以下命令：

sc create OllamaService binPath= "C:\Path\To\run_ollama.bat"

确保将 C:\Path\To\run_ollama.bat 替换为实际的运行脚本路径。创建服务后，你可以使用以下命令设置服务自动启动：

sc config OllamaService start= auto

验证和测试#

完成上述步骤后，重启计算机并检查 Ollama 是否自动启动且没有弹出黑窗口。如果一切正常，你应该可以在系统后台看到 Ollama 的运行状态。

配置优化#

为了进一步优化，可以考虑使用 Task Scheduler 来定时检查 Ollama 是否正常运行，如果进程不存在则自动重启。创建一个新的任务，设置触发器为“在系统启动时”，操作为启动 Ollama 的运行脚本。

<Triggers>
    <BootTrigger />
</Triggers>
<Actions>
    <Exec>
        <Command>C:\Path\To\run_ollama.bat</Command>
    </Exec>
</Actions>

总结#

通过上述步骤，你可以在 Windows 系统中实现 Ollama 的开机自启动，并且不弹出黑窗口。这不仅能够确保 Ollama 持续稳定运行，还提升了系统的美观性和用户体验。希望本文对你有所帮助。
