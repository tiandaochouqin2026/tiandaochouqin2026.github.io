RTX 4070 SUPER 12G 跑 Qwen2.5-14B 完整教程（Windows + Ollama）

用一张 4070 SUPER 12G 在 Windows 上部署 Qwen2.5-14B 的全过程：下载、模型拉取、局域网访问、实测速度。
September 21, 2026 · 2 min · Local AI Lab | Translations:
  • En

硬件与结论#

项目 配置
显卡 RTX 4070 SUPER（12GB 显存）
模型 Qwen2.5-14B-Instruct（Q4_K_M 量化，约 9GB）
软件 Ollama for Windows 0.34
实测速度 预热后约 49 tokens/s（100% GPU）

结论：12G 显存跑 14B Q4 完全合适。模型本体约 9GB，加上上下文 KV cache 后基本不爆显存。

第一步：安装 Ollama#

从 ollama.com/download 下载 Windows 安装包，双击静默安装即可。

踩坑提示：官网实际把安装包托管在 GitHub Release。如果你在国内网络下直连下载失败，报 “Could not resolve host: github.com”，可以换 GitHub 加速镜像（如 ghproxy 类前缀）再试。

安装完成后，打开 cmd 验证：

ollama --version

第二步：拉取模型#

ollama pull qwen2.5:14b

模型约 9GB，下载速度取决于你的网络。拉完后用 ollama list 确认。

第三步：验证推理#

ollama run qwen2.5:14b

直接进入对话模式，输入一句话测试。首次推理会加载模型到显存，大约 10-20 秒。

第四步：开放局域网访问（可选）#

Ollama 默认只监听 127.0.0.1:11434，手机或其他电脑访问不到。设置环境变量后重启即可：

[Environment]::SetEnvironmentVariable('OLLAMA_HOST','0.0.0.0','User','User')

重启 Ollama 服务后，局域网设备就能通过 http://<你的内网IP>:11434 访问 API。

显存占用实测#

上下文长度 GPU 占用 速度
4096 100% GPU ~49 tok/s
32768 34% CPU + 66% GPU 明显变慢

12G 显存放 14B Q4 后，KV cache 空间有限。长上下文场景会自动溢出到内存，速度下降。日常对话 4K 上下文完全够用。

写在最后#

本地跑 14B 模型的意义不是"比 GPT-4 强"，而是：数据不出本机、没有 API 费用、可以断网使用、可以随便调教。如果你也有一张 12G 以上的卡，这一步值得做。
