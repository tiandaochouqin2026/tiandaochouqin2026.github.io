用 OpenClaw 接 Telegram：在手机上和本地模型聊天

通过 OpenClaw 在 Telegram 上使用本地部署的 Ollama 语言模型。
September 24, 2026 · 2 min · Local AI Lab | Translations:
  • En

部署本地语言模型并使其在移动设备上可用，能显著减少数据传输开销和提高响应速度。本教程介绍如何通过 OpenClaw，将本地的 Ollama 模型与 Telegram 集成，实现在手机上直接与本地模型进行对话。

环境准备#

  • 硬件：最低配置要求为4GB RAM，推荐8GB RAM或更高。
  • 软件：Windows 10或更高版本，Python 3.8以上版本。
  • 模型：下载并安装 Ollama，建议使用较小的模型如llama-7b以减少资源消耗。

安装 OpenClaw#

  1. 克隆 OpenClaw 仓库：

    git clone https://github.com/OpenClaw/OpenClaw.git
cd OpenClaw

  2. 安装依赖：

    pip install -r requirements.txt

配置 Ollama#

  1. 安装 Ollama 模型：

    ollama install llama-7b

  2. 启动 Ollama 服务：

    ollama run llama-7b

  3. 设置 Ollama 的 API 地址：

    {
    "api": "http://localhost:5000"
}

配置 OpenClaw#

  1. 编辑 OpenClaw 的配置文件 config.yaml，添加 Ollama 的 API 地址：

    ollama_api:
    host: "localhost"
    port: 5000

  2. 安装 Telegram Bot API：

    pip install python-telegram-bot

  3. 创建 Telegram Bot：

    • 访问 https://t.me/BotFather。
    • 生成一个新的 Telegram Bot 并获取 API Token。

  4. 编辑 OpenClaw 的配置文件，添加 Telegram Bot 的 Token：

    telegram:
    token: "YOUR_TELEGRAM_BOT_TOKEN"

集成 Telegram 和 Ollama#

  1. 编写 Telegram Bot 的消息处理逻辑，用于与 Ollama 交互。例如，当接收到用户消息时，调用 Ollama 的 API 进行处理： 
    from telegram import Update
from telegram.ext import Updater, CommandHandler, MessageHandler, Filters, CallbackContext
import requests

def start(update: Update, context: CallbackContext) -> None:
    update.message.reply_text('Hello! Send me a message and I will reply with the OpenClaw response.')

def echo(update: Update, context: CallbackContext) -> None:
    response = requests.get(f"http://localhost:5000/generate", json={"prompt": update.message.text})
    update.message.reply_text(response.json()['response'])

def main() -> None:
    updater = Updater("YOUR_TELEGRAM_BOT_TOKEN")
    dispatcher = updater.dispatcher

    dispatcher.add_handler(CommandHandler("start", start))
    dispatcher.add_handler(MessageHandler(Filters.text & ~Filters.command, echo))

    updater.start_polling()
    updater.idle()

if __name__ == '__main__':
    main()

运行 OpenClaw#

  1. 启动 OpenClaw 服务：

    python start.py

  2. 在 Telegram 上与您的 Bot 交互，验证消息是否能正常传递给 Ollama 并获得响应。

总结#

通过上述步骤，您已经成功地将本地部署的 Ollama 模型与 Telegram 集成，可以在手机上直接与模型进行对话。这不仅提供了便利性，还提高了数据的安全性和隐私性。希望本教程能帮助您快速实现这一功能，并为您的开发项目提供灵感。
