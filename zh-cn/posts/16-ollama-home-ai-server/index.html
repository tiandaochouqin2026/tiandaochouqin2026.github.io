把 Ollama 做成全家共用的 AI 服务：局域网、手机、平板都能连

部署 Ollama 服务器，实现全家共享AI服务，支持局域网访问。
November 23, 2026 · 2 min · Local AI Lab | Translations:
  • En

引言#

本文将介绍如何在 Windows 11 系统上部署 Ollama 服务，通过局域网实现全家共享的 AI 服务。使用 NVIDIA RTX 4070 SUPER GPU 和 AMD 平台，可以流畅运行 qwen2.5:14b 和 gemma4:12b 等大模型，实现在不同设备上的灵活访问。

环境配置#

确保系统已经安装了最新版本的 Ollama (0.34.2) 和 OpenClaw (2026.9.5)。在配置过程中，需要调整 Modelfile 文件以适应不同设备的需求。例如，对于 qwen2.5 模型，可以使用以下配置：

FROM qwen2.5:14b
SYSTEM -m 9.0GB
PARAMETER num_ctx 4096
PARAMETER temperature 0.7
PARAMETER stop "句号"

局域网部署#

在 Windows 11 上部署 Ollama 服务，需要确保服务能够通过局域网被其他设备访问。首先，配置 Ollama 的网络监听端口，使其可以接收来自其他设备的请求。修改 Ollama 的配置文件，添加如下命令：

docker run --name ollama -p 8080:8080 -d ollama/ollama:latest

然后，使用以下命令启动 Ollama 服务：

ollama start

配置完成后，可以通过浏览器访问 http://<服务器IP>:8080 来测试 Ollama 服务是否正常工作。

手机和平板访问#

为了让手机和平板能够访问 Ollama 服务，需要在这些设备上安装 Ollama 的客户端应用。以手机为例，安装 Ollama 的 Android 客户端应用后，可以通过在应用内输入服务器 IP 地址来连接到 Ollama 服务。

在平板电脑上，可以使用 Chrome 或其他支持 HTTP 请求的浏览器来访问 Ollama 服务。配置好网络环境后，可以在手机和平板上轻松使用 AI 服务。

性能优化#

在部署过程中，需要对模型的性能进行优化，以满足不同设备的需求。例如，对于 qwen2.5:14b 模型，在 4096 context 下的处理速度为约 49 tok/s，而 32768 context 下的处理速度则约为 15-20 tok/s。根据实际应用场景，可以调整模型参数，以达到最佳性能。

结论#

通过上述步骤，可以成功地在 Windows 11 上部署 Ollama 服务，并通过局域网实现全家共享的 AI 服务。无论是在手机、平板还是其他设备上，用户都可以方便地访问和使用这些强大的 AI 模型。
