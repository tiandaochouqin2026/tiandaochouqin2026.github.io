用 VS Code + Continue 接本地模型：不联网也能写代码

如何在本地部署大模型，并通过VS Code插件Continue进行代码编辑，实现在没有网络的情况下也能高效编程。
November 23, 2026 · 2 min · Local AI Lab | Translations:
  • En

在本地部署大模型并通过VS Code插件Continue进行代码编辑，可以让你在没有网络连接的情况下也能高效编程。本文将详细介绍如何在Windows 11系统上使用Ollama部署本地大模型，并通过VS Code插件Continue进行实时代码建议。我的机器配置为：NVIDIA RTX 4070 SUPER 12GB VRAM，AMD CPU，32GB RAM，已安装模型包括qwen2.5:14b、gemma4:12b和hermes-agent。

部署Ollama#

首先，确保你已经安装了Ollama，其版本为0.34.2。接着，你需要下载并配置模型。以下是针对qwen2.5:14b的Modelfile配置文件示例：

FROM ollama/qwen2.5:14b
SYSTEM Windows 11
PARAMETER temperature 0.7
PARAMETER num_ctx 8192
PARAMETER stop "EOF"

使用Ollama命令进行模型部署：

ollama run qwen2.5:14b

配置VS Code插件Continue#

继续使用VS Code插件Continue，你需要先安装该插件。安装完成后，你需要配置插件以连接到本地部署的模型。在VS Code中，打开命令面板（Ctrl+Shift+P），然后输入“Continue: Connect”，选择你的本地Ollama实例。

接下来，你需要设置VS Code的启动配置，以便在每次打开VS Code时自动连接到本地模型。在VS Code的设置中，添加以下配置：

{
    "continue.server": "http://127.0.0.1:8000",
    "continue.model": "qwen2.5:14b",
    "continue.context": 4096
}

这样配置后，你可以在不联网的情况下使用VS Code进行代码编辑和代码建议。

性能优化#

为了更好地使用本地模型，需要关注模型的性能。在我的机器上，使用qwen2.5:14b时，4096 context下的吞吐量约为49 tok/s，100% GPU，占用9.5GB VRAM。32768 context下，吞吐量约为15-20 tok/s，34% CPU + 66% GPU，总共占用约15GB内存。

你可以通过调整num_ctx参数来优化性能，如将num_ctx设置为4096以获得更好的性能和较低的内存占用。

结论#

通过本文的介绍，你应该能够将大模型部署到本地环境中，并通过VS Code插件Continue进行实时代码编辑。这项技术使得在没有网络连接的情况下也能高效地进行编程和开发，大大提高了本地开发环境的灵活性和实用性。
