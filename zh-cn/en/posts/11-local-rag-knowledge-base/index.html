set-up-a-rag-knowledge-base-locally-with-qwen2-5

how to use qwen2.5 to set up a rag knowledge base locally and integrate pdf and notes
November 20, 2026 · 1 min · Local AI Lab

Setting up a RAG (Retrieval-Augmented Generation) knowledge base locally allows qwen2.5 to better handle and answer questions related to local documents. This article will introduce how to use the Ollama service to integrate PDFs and notes into a local knowledge base.

Preparation#

  1. Ensure that ollama is installed and can be used normally.
  2. Prepare the PDF and note files to be imported and place them in an easily accessible directory.

Install Dependencies#

pip install ollama

Upload PDF Files#

  1. First, upload the PDF files to the designated directory on the local server.
cd /path/to/your/files
  1. Use the ollama ingest command to convert and upload the PDF files to the knowledge base.
ollama ingest -t pdf -i /path/to/your/files/*.pdf -o /path/to/your/output
  • The -t parameter specifies the file type, which is pdf in this case.
  • The -i parameter specifies the input file path.
  • The -o parameter specifies the output directory, where the generated vector files will be stored.

Integrate Note Files#

  1. Upload the note files (e.g., Markdown files) to the server.
  2. Use the ollama ingest command to convert and upload the note files.
ollama ingest -t markdown -i /path/to/your/note/*.md -o /path/to/your/output
  • Change the -t parameter to markdown.
  • The -i parameter specifies the path to the note files.

Configure the Knowledge Base#

  1. Create or modify the ollama.yaml file to configure the knowledge base.
sources:
  - name: local-kb
    type: local
    path: /path/to/your/output
  1. Use the ollama create command to create the knowledge base.
ollama create local-kb -f ollama.yaml

Start the Service#

ollama run local-kb

Now, you can interact with the local knowledge base via the API provided by Ollama.

Testing#

curl -X 'POST' \
  'http://localhost:8000/knowledge/local-kb/query' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "query": "本地知识库包含哪些内容？",
  "top_k": 5
}'

Summary#

Through the above steps, you have successfully integrated PDF and note files into the local knowledge base and can now query and use these resources through the services provided by Ollama. This provides a strong knowledge base for qwen2.5, enabling it to better serve information queries and generation tasks in specific domains.
