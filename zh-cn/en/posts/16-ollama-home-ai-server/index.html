deploy-ollama-as-family-shared-ai-service

deploy ollama server to enable family-wide sharing of ai services, accessible via local network.
November 23, 2026 · 1 min · Local AI Lab

Introduction#

This article will guide you through deploying the Ollama service on a Windows 11 system to enable a family-wide shared AI service accessible via a local network. With an NVIDIA RTX 4070 SUPER GPU and AMD platform, large models like qwen2.5:14b and gemma4:12b can run smoothly, allowing flexible access across different devices.

Environment Setup#

Ensure that the latest version of Ollama (0.34.2) and OpenClaw (2026.9.5) are installed on the system. During configuration, adjust the Modelfile to suit the needs of different devices. For example, for the qwen2.5 model, the following configuration can be used:

FROM qwen2.5:14b
SYSTEM -m 9.0GB
PARAMETER num_ctx 4096
PARAMETER temperature 0.7
PARAMETER stop "句号"

Local Network Deployment#

To deploy the Ollama service on Windows 11 and make it accessible via a local network, ensure that the service can receive requests from other devices. First, configure Ollama to listen on a network port by modifying the Ollama configuration file and adding the following command:

docker run --name ollama -p 8080:8080 -d ollama/ollama:latest

Then, start the Ollama service with the following command:

ollama start

After configuration, you can test if the Ollama service is working correctly by accessing http://<serverIP>:8080 in a browser.

Access from Mobile and Tablet Devices#

To allow mobile and tablet devices to access the Ollama service, install the Ollama client application on these devices. For example, after installing the Ollama Android client app on a phone, connect to the Ollama service by entering the server IP address within the app.

On a tablet, use Chrome or another browser that supports HTTP requests to access the Ollama service. After setting up the network environment, you can easily use the AI service on mobile and tablet devices.

Performance Optimization#

During deployment, optimize the model’s performance to meet the needs of different devices. For instance, the qwen2.5:14b model processes at approximately 49 tok/s with a 4096 context, while the processing speed drops to around 15-20 tok/s with a 32768 context. Adjust the model parameters according to the actual use case to achieve optimal performance.

Conclusion#

By following the above steps, you can successfully deploy the Ollama service on Windows 11 and enable a family-wide shared AI service accessible via a local network. Users can conveniently access and use these powerful AI models on phones, tablets, or other devices.
